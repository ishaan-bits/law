# D. Sterre Hoving - Portfolio

A dynamic, interactive portfolio website for D. Sterre Hoving, law student specializing in International and European Law at the University of Groningen.

## Tech Stack

- **Framework:** Next.js 16 with TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React

## Features

- Dark premium theme with gold accents
- Parallax hero section with animated background
- Interactive 3D tilt cards for certificates
- Animated progress bars for language proficiency
- Smooth scroll navigation with glass morphism
- Responsive design for all screen sizes
- Contact form with loading states

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
